# glow_sd

**glow_sd** は、リニア色空間での輝度抽出、ピラミッド型ブラー、および 12 種類のトーンマッピングを備えた **AviUtl ExEdit2** 用のグロー（ブルーム）アニメーション効果スクリプトです。

## 機能・特徴

* **リニア色空間処理**
  sRGB 入力をストレートアルファ変換およびリニア色空間へ変換してから輝度抽出・ブラー・加算合成を行い、出力前に sRGB へ戻します。半透明境界の黒ずみを防ぎ、光学的な加算特性に沿った減衰・合成を行います。

* **ピラミッド型ブラー（GPU 処理）**
  13 タップのダウンサンプリングと 9 タップのアップサンプリングを組み合わせたマルチパスブラーを HLSL ピクセルシェーダー上で実行します。最大 `2000px` の拡散半径や、縦横比・回転角度を指定した異方性ブラーに対応しています。

* **12 種類のトーンマッピング**
  `1.0` を超える高輝度域の白飛びを抑えるトーンカーブ（`フィルムロールオフ`、`ACES Fitted`、`AgX`、`Khronos PBR Neutral`、`Uchimura`、`Uncharted 2`、`Reinhard` など）を選択できます。

* **輝度抽出およびカラーキー抽出**
  人間の視覚特性に基づく `Rec.709` 輝度と、原色を均等に抽出する `RGB 最大値` の切り替えに加え、特定の色相・彩度付近のみを抽出するカラーキー機能を備えています。

* **ディザリングによる階調飛び抑制**
  最終出力時にフレーム単位の微小ディザリングを適用し、広範囲かつ淡いグラデーションに生じるバンディング（マッハバンド）を軽減します。

* **単一ファイル構成・フィルタオブジェクト対応**
  外部 DLL や追加ランタイムは不要です。`glow_sd.anm2` 単体で動作し、通常オブジェクトとフィルタオブジェクトの両方に適用できます。

## 動作環境

* **AviUtl ExEdit2**（v2.1.14 以降推奨）

## インストール方法

1. GitHub の [Releases](../../releases) またはページ上部の `Code` > `Download ZIP` からファイルをダウンロードし、解凍します。
2. `glow_sd.anm2` を AviUtl2 のスクリプトフォルダに配置します。
   * **標準の配置先:** `C:\ProgramData\aviutl2\Script\`
   * **ポータブル版の配置先:** AviUtl2 本体フォルダ内の `Script\` または `data\Script\` フォルダ
3. AviUtl2 を起動（または再起動）すると、以下のメニューから選択できます。
   * **アニメーション効果:** `光効果` > `グロー_sd`
   * **フィルタオブジェクト:** `光効果` > `グロー_sd`

## パラメータ説明

### 抽出・露出

光らせる領域の判定基準と、抽出する光の強さを設定します。

| パラメータ名 | 種類 / 範囲 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- |
| **抽出基準** | 選択 | `最大値(イラスト向け)` | 抽出判定に使用する明るさの計算方式を選択します（詳細は下記参照）。 |
| **抽出閾値** | `0.00 ～ 1.00` | `0.20` | グローを発生させるリニア輝度の基準値です。値を下げると暗い領域も抽出され、上げると明るい領域のみが抽出されます。`0.00` では黒（`0.0`）以外の全領域が対象になります。 |
| **閾値の柔らかさ** | `0.00 ～ 1.00` | `0.50` | 閾値付近の抽出境界を滑らかにする（ソフトニー）幅の係数です。`0.00` では閾値を境に抽出が急に切り替わり、値を上げると閾値より少し暗い部分から段階的に抽出が始まります。 |
| **発光強度** | `0.00 ～ 20.00` | `1.00` | 抽出した光に乗算する露出倍率です。ブラーおよびトーンマッピングの前に乗算されるため、値を上げると明るさが増すと同時にトーンマッピングによる高輝度圧縮が強くかかります。 |
| **ハイライト強調** | `0.00 ～ 10.00` | `1.00` | 閾値を超えた量に応じた追加の増幅率です。`1.00` で線形、`1.00` より大きいと閾値を大きく超える高輝度部分ほど強く増幅されます。`1.00` 未満では高輝度部の突出が抑えられます。 |
| **特定色のみ抽出** | チェックボックス | `OFF` | `ON` にすると、ピクセルの色度（RGB 比率）が `抽出対象色` に近い領域のみを抽出します。`ON` にすると下の 3 項目が表示されます。 |
| **抽出対象色** | カラー | `#FF0000` (赤) | ※「特定色のみ抽出」が `ON` のときに表示。抽出の基準となる色を指定します。明度ではなく RGB の比率で判定されます。 |
| **色の許容幅** | `0.01 ～ 1.00` | `0.25` | ※同上。`抽出対象色` からの色度距離の許容上限です。小さいほど指定色に一致する色のみに限定され、大きいほど周辺の色相・彩度も含まれます。 |
| **色の境界の柔らかさ** | `0.00 ～ 1.00` | `0.50` | ※同上。`色の許容幅` の境界におけるフェード幅です。`0.00` で境界が二値的に切り替わり、値を上げると境界付近が滑らかに減衰します。 |

* **抽出基準の選択肢**
  * `Rec.709(実写向け)`: 人間の視覚特性に基づく輝度（$0.2126R + 0.7152G + 0.0722B$）で判定します。白や黄色は高く評価され、純粋な青は低く評価される（`0.0722`）ため、実写映像で青色だけが過剰に発光するのを防ぎます。
  * `最大値(イラスト向け)`: R・G・B の最大成分（$\max(R, G, B)$）を明るさとして判定します。純色の青や赤でも `1.0` として扱われるため、彩度の高い原色を均等に発光させたいイラストやモーショングラフィックスに適しています。

### 拡散・減衰

光の広がり方、異方性（縦横比）、および減衰バランスを設定します。

| パラメータ名 | 種類 / 範囲 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- |
| **拡散半径** | `0 ～ 2000` | `100` | 光が広がる範囲の基準値（単位: ピクセル）です。ピラミッドブラーの階層数（最大 11 パス）および自動領域拡張の余白量を決定します。`0` の場合はブラー処理をスキップします。 |
| **サンプリング幅** | `0.10 ～ 5.00` | `1.00` | 各ぼかしパスにおけるテクスチャサンプリング間隔の倍率です。`1.00` より大きくすると階層数を増やさずに拡散範囲を広げられますが、細い線や点光源に対して大きくしすぎると格子状のムラが出ます。`1.00` 未満では密度の高い滑らかなぼかしになります。 |
| **縦横拡散比** | `-1.00 ～ 1.00` | `0.00` | 拡散の縦横比率を変更します。`0.00` で円形、正の値（`0.01 ～ 1.00`）で横長、負の値（`-1.00 ～ -0.01`）で縦長の楕円状に拡散します。`1.00` または `-1.00` で片軸の拡散が `0` になります。 |
| **拡散の回転角度** | `-360.0 ～ 360.0` | `0.0` | `縦横拡散比` を変更している場合の拡散方向を回転させます（単位: 度）。`縦横拡散比` が `0.00` の場合は見た目上の変化はありません。 |
| **減衰の滑らかさ** | `0.50 ～ 4.00` | `2.00` | ピラミッド各階層の合成重み（$2^{2 - \text{値}}$）を調整します。`2.00` で全階層が均等になり、`2.00` より大きいと中心付近が濃く周辺が急激に消えます。`2.00` 未満では外周部まで明るく均一に広がります。 |
| **芯の強調** | `0.00 ～ 5.00` | `0.00` | ブラーをかけていない元の抽出領域（最上位階層）の加算比率を増やします。値を上げるとぼやけた光の中心に元の輪郭の芯が残り、相対的に周辺の淡い光が抑えられます。 |

### カラー・オプション

トーンマッピング時の色相維持、単色化、および RGB チャンネルごとの拡散減衰を調整します。

| パラメータ名 | 種類 / 範囲 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- |
| **色相・彩度を維持** | チェックボックス | `ON` | ※「トーン制御」が `なし` 以外のときに表示。`ON` にすると輝度（Rec.709）に対してトーンカーブを計算し、元の RGB 比率を保ったまま圧縮します。`OFF` にすると RGB 各チャンネル個別に圧縮するため、高輝度部分が白方向へ色相変化します。 |
| **単色グロー化** | チェックボックス | `OFF` | `ON` にすると、抽出した光の元の色を無視し、抽出輝度に `グロー色` を掛けた単色の光に置き換えます。`ON` にすると下の `グロー色` が表示されます。 |
| **グロー色** | カラー | `#FFFFFF` (白) | ※「単色グロー化」が `ON` のときに表示。単色グロー化に使用する発光色を指定します。 |
| **波長拡散補正** | `0.00 ～ 2.00` | `1.00` | **赤拡散補正 / 緑拡散補正 / 青拡散補正** の 3 パラメータで構成されます。アップサンプリングの各階層でチャンネルごとに減衰係数を乗算します。`1.00` より大きい色は外周まで残りやすく、`1.00` 未満の色は中心付近で減衰します。 |

### 出力・合成

最終的な明るさ、描画領域、トーンマッピング方式、および合成モードを設定します。

| パラメータ名 | 種類 / 範囲 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- |
| **合成強度** | `0.00 ～ 20.00` | `1.00` | ブラー処理後のグロー全体に乗算する最終的な明るさ倍率です。`0.00` にするとブラー処理をスキップします。 |
| **発光範囲** | 選択 | `全体` | ※「合成モード」が `抽出プレビュー` 以外のときに表示。グローを描画する領域を指定します（詳細は下記参照）。 |
| **トーン制御** | 選択 | `フィルムロールオフ` | 合成後のリニア HDR 値を `0.0 ～ 1.0` の表示範囲へ圧縮するトーンマッピング方式を選択します（詳細は下記参照）。 |
| **トーン調整** | `0.10 ～ 10.00` | `1.00` | ※「トーン制御」が `なし` 以外のときに表示。選択したトーンカーブの圧縮強度（ロールオフ係数または露出係数）を調整します。 |
| **合成モード** | 選択 | `加算` | 元画像とグローの合成方式を選択します（詳細は下記参照）。 |

* **発光範囲の選択肢**
  * `全体`: 元画像の上および外側の透明領域の両方にグローを描画します。
  * `外側のみ`: 元画像の不透明部分にはグローを描画せず、外側の透明領域にのみ描画します。文字や切り抜き素材の輪郭の外側だけを発光させる場合に使用します。
  * `内側のみ`: 元画像の不透明領域の内部にのみグローを描画し、外側にははみ出させません。この選択時は自動領域拡張を行いません。

* **トーン制御の選択肢（全 13 種）**
  > **注意:** `なし` 以外を選択した場合、グローが重なっていない元画像部分も含め、オブジェクト全体にトーンカーブが適用されます。元画像の色味やコントラストを変化させたくない場合は `なし` を選択してください。
  * `なし`: トーン圧縮を行わず、`1.0` を超える値を切り捨て（クリップ）ます。
  * `フィルムロールオフ`: 指数関数（$1 - e^{-x \cdot r}$）による圧縮です。高輝度に向かって滑らかに減衰します。
  * `ACES(近似)`: ACES フィルムトーンカーブの高速近似式です。コントラストが高めで、ハイライトが締まります。
  * `Reinhard`: 拡張 Reinhard 演算子です。`トーン調整` で白飛び点（ホワイトポイント）を制御しながら全体を緩やかに圧縮します。
  * `Uncharted 2`: Hable 氏によるフィルムカーブです。シャドウからハイライトまで階調を広く保ちます。
  * `ソフトカーブ`: べき乗を組み合わせた軟調なロールオフです。高輝度部の立ち上がりが緩やかになります。
  * `S字カーブ`: シグモイド関数によるコントラスト強調型のカーブです。中間調の明暗差が強くなります。
  * `ソフトクリップ`: 一定閾値までは線形（元の明るさを維持）で、閾値を超えた高輝度部分のみ指数関数で圧縮します。暗部から中間調の明るさを変えたくない場合に適しています。
  * `Lottes Filmic`: Lottes 氏によるトーンカーブです。中間調（`0.18`）を基準にコントラストと高輝度のロールオフを制御します。
  * `Uchimura`: 内村氏によるトーンカーブです。線形領域を維持しつつ、ハイライトの肩を滑らかに圧縮します。
  * `Khronos PBR Neutral`: Khronos Group 策定のトーンマッピングです。`0.8` 付近まで色を変化させず、高輝度域で色相を保ったまま緩やかに脱色します。
  * `ACES Fitted`: 行列変換を用いた高精度な ACES フィットカーブです。
  * `AgX`: 広色域対応のトーンマッピングです。高輝度域での自然な脱色と色相維持のバランスに優れます。

* **合成モードの選択肢**
  * `加算`: リニア色空間で元画像にグローを加算します（$\text{orig} + \text{glow}$）。
  * `スクリーン`: リニア色空間で元画像の明るさに応じてグローの加算量を抑えます（$\text{orig} + \frac{\text{glow}}{1 + \text{orig}}$）。元画像がすでに明るい領域での白飛びを抑えます。
  * `グローのみ`: 元画像を出力せず、グロー成分とアルファチャンネルのみを出力します。別レイヤーで合成モードを変更したい場合やマスク用途に使用します。
  * `抽出プレビュー`: ブラー処理と元画像との合成を行わず、現在抽出されている領域のみを表示します。

## パラメータ調整のポイント

* **抽出範囲の確認**
  `合成モード` を一時的に `抽出プレビュー` に切り替えると、現在の `抽出閾値` や `特定色のみ抽出` でどの領域がどれくらいの強さで抽出されているかを直接確認できます。調整完了後に `加算` や `スクリーン` へ戻します。
* **「発光強度」と「合成強度」の使い分け**
  `発光強度` はトーンマッピングの**前**に作用するため、値を上げると光が白く飽和しやすくなります。`合成強度` はトーンマッピングの**直前（ブラー後）**に全体へ掛かる倍率です。光の芯を白く飛ばしたい場合は `発光強度` を上げ、色を保ったまま全体の明るさを調整したい場合は `合成強度` を調整します。
* **色収差風の滲みを作る**
  `波長拡散補正` で、`赤拡散補正` を `1.15`、`青拡散補正` を `0.85` のようにチャンネルごとに異なる値を設定すると、光の輪郭に赤や青の色づきが生じます。
* **横長・斜めの光条を作る**
  `縦横拡散比` を `0.70 ～ 0.95` に設定すると横方向に伸びる楕円状のグローになります。`拡散の回転角度` を変更すると斜め方向へ傾けることができます。

## 仕様上の補足

* **リニア色空間での閾値について**
  `抽出閾値` はリニア色空間上の値（`0.00 ～ 1.00`）で判定されます。sRGB 空間の数値とは非線形に対応しており、たとえば sRGB の 50% グレー（`#808080`）はリニア空間では約 `0.216` になります。
* **自動領域拡張について**
  通常オブジェクトへ適用した場合、`拡散半径`・`サンプリング幅`・`縦横拡散比`・`拡散の回転角度` から必要な余白を計算し、自動で「領域拡張」を実行します（`発光範囲` が `内側のみ` の場合、および `抽出プレビュー` 時を除く）。拡張後のサイズは AviUtl2 の最大画像サイズ（`image_max`）を超えない範囲に制限されます。
* **フィルタオブジェクト適用時の挙動**
  フィルタオブジェクトとして適用した場合は、AviUtl2 の仕様上「領域拡張」が行われないため、画面端の輝度が欠けて暗くなるのを防ぐ目的でサンプラーモードを `clamp` に切り替えて処理します。
