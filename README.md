# glow_sd

**glow_sd** は、リニア色空間での輝度抽出、高品質なピラミッド型ブラー、および 12 種類のトーンマッピングを備えた **AviUtl ExEdit2** 用のグロー（ブルーム）アニメーション効果スクリプトです。

## 機能・特徴

- **物理的に自然なリニア色空間処理**
  sRGB 入力をストレートアルファ変換・リニア色空間変換してから輝度抽出・ブラー・加算合成を行い、出力前に sRGB へ戻します。半透明境界の黒ずみを防ぎ、現実の光学現象に近い自然な光の減衰・合成が得られます。
- **広範囲・高速なピラミッド型ブラー**
  13 タップのダウンサンプリングと 9 タップのアップサンプリングを組み合わせたマルチパスブラーを GPU（HLSL ピクセルシェーダー）上で処理します。最大 `2000px` の広大な拡散半径や、縦横比・角度を指定した異方性グロー（アナモルフィック風）にも対応します。
- **12 種類のトーンマッピング搭載**
  高輝度域の白飛びを滑らかに抑えるトーンカーブを 12 種類（`フィルムロールオフ`、`ACES Fitted`、`AgX`、`Khronos PBR Neutral`、`Uchimura`、`Uncharted 2`、`Reinhard` など）内蔵しています。
- **柔軟な発光領域の抽出**
  人間の視覚特性に基づく `Rec.709` 輝度と、純色も綺麗に光らせる `RGB 最大値` の切り替えに加え、特定の色相・彩度付近のみを抽出するカラーキー機能を備えています。
- **バンディング（階調飛び）抑制**
  最終出力時にフレーム単位の微小ディザリングを適用し、広範囲かつ淡いグローのグラデーションに生じやすいマッハバンドを軽減します。
- **単一ファイル構成・フィルタオブジェクト対応**
  外部 DLL や追加ランタイムは不要です。`glow_sd.anm2` 単体で動作し、通常オブジェクトだけでなくフィルタオブジェクトとしても適用できます。

## インストール方法

1. GitHub の [Releases](../../releases) またはページ上部の `Code` > `Download ZIP` からファイルをダウンロードし、解凍します。
2. `glow_sd.anm2` を AviUtl2 のスクリプトフォルダに配置します。
   - **標準の配置先:** `C:\ProgramData\aviutl2\Script\`
   - **ポータブル版の配置先:** AviUtl2 本体フォルダ内の `Script\` または `data\Script\` フォルダ
3. AviUtl2 を起動（または再起動）すると、以下のメニューから選択できるようになります。
   - **アニメーション効果:** `光効果` > `glow_sd`
   - **フィルタオブジェクト:** `光効果` > `glow_sd`

## パラメータ説明

### 抽出・露出

光らせる領域の判定基準や、抽出した光の強さを設定します。

| パラメータ名 | 種類 / 範囲 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- |
| **抽出基準** | 選択 | `最大値(イラスト向け)` | 明るさの判定方法を選択します（詳細は下記参照）。 |
| **抽出閾値** | `0.00 ～ 1.00` | `0.20` | グローを発生させる明るさの基準値です。値を下げると暗い部分も発光します。 |
| **閾値の柔らかさ** | `0.00 ～ 1.00` | `0.50` | 閾値付近の抽出境界を滑らかにする（ソフトニー）度合いです。`0.00` で硬い境界になります。 |
| **発光強度** | `0.00 ～ 20.00` | `1.00` | 抽出した光に乗算する露出強度です。 |
| **ハイライト強調** | `0.00 ～ 10.00` | `1.00` | 閾値を大きく超える高輝度部分に対する追加の増幅率です。 |
| **特定色のみ抽出** | チェックボックス | `OFF` | `ON` にすると、指定した色に近い領域のみを抽出対象とします。 |
| **抽出対象色** | カラー | `#FF0000` (赤) | ※「特定色のみ抽出」が `ON` のときに表示。抽出の基準となる色を指定します。 |
| **色の許容幅** | `0.01 ～ 1.00` | `0.25` | ※同上。対象色からどの程度離れた色まで許容するかを指定します。 |
| **色の境界の柔らかさ** | `0.00 ～ 1.00` | `0.50` | ※同上。色判定境界のフェード幅を指定します。 |

- **抽出基準の選択肢**
  - `Rec.709(実写向け)`: 人間の視覚特性に基づく輝度（$0.2126R + 0.7152G + 0.0722B$）で判定します。白や黄色が自然に光り、青色が過剰に光るのを抑えます。
  - `最大値(イラスト向け)`: R・G・B の最大成分を基準に判定します。純色に近い原色（青や赤など）も均等に発光させたいイラスト・アニメ調の素材に適しています。

### 拡散・減衰

光の広がり方や減衰のバランスを設定します。

| パラメータ名 | 種類 / 範囲 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- |
| **拡散半径** | `0 ～ 2000` | `100` | 光が広がる範囲をピクセル単位で指定します。`0` の場合はブラー処理をスキップします。 |
| **サンプリング幅** | `0.10 ～ 5.00` | `1.00` | 各ぼかしパスにおけるサンプリング間隔の倍率です。大きくすると広範囲に広がりますが、解像度によっては格子状のムラが出る場合があります。 |
| **縦横拡散比** | `-1.00 ～ 1.00` | `0.00` | 拡散の縦横比率を変更します。正の値で横方向、負の値で縦方向に伸びる異方性グローになります。 |
| **拡散の回転角度** | `-360.0 ～ 360.0` | `0.0` | `縦横拡散比` を変更している場合の拡散方向を回転させます。 |
| **減衰の滑らかさ** | `0.50 ～ 4.00` | `2.00` | ピラミッド各階層における減衰率のバランスを調整します。大きいほど中心付近が濃く、小さいほど外周まで均一に広がります。 |
| **芯の強調** | `0.00 ～ 5.00` | `0.00` | ぼかしのない元の抽出領域（中心の芯）の割合を増やし、輪郭の芯を際立たせます。 |

### カラー・オプション

発光色の変更や、RGB チャンネルごとの滲み方を調整します。

| パラメータ名 | 種類 / 範囲 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- |
| **色相・彩度を維持** | チェックボックス | `ON` | ※「トーン制御」が `なし` 以外のときに表示。輝度ベースでトーンカーブを適用し、ハイライトの白飛びによる色相ズレを抑えます。 |
| **単色グロー化** | チェックボックス | `OFF` | `ON` にすると、抽出した光の色を下の「グロー色」に置き換えます。 |
| **グロー色** | カラー | `#FFFFFF` (白) | ※「単色グロー化」が `ON` のときに表示。単色グロー化に使用する発光色です。 |
| **波長拡散補正** | `0.00 ～ 2.00` | `1.00` | **赤拡散補正 / 緑拡散補正 / 青拡散補正** のグループです。各チャンネルごとにアップサンプリング時の減衰係数を補正し、特定の色の滲みを強めたり弱めたりできます。 |

### 出力・合成

最終的な明るさ、描画範囲、トーンマッピング、合成方法を設定します。

| パラメータ名 | 種類 / 範囲 | 初期値 | 説明 |
| :--- | :--- | :--- | :--- |
| **合成強度** | `0.00 ～ 20.00` | `1.00` | 最終合成時のグローの明るさ倍率です。`0.00` で処理をスキップします。 |
| **発光範囲** | 選択 | `全体` | グローを描画する領域を指定します（詳細は下記参照）。 |
| **トーン制御** | 選択 | `フィルムロールオフ` | HDR 値を `0.0 ～ 1.0` の表示範囲へ圧縮するトーンマッピング方式を選択します。 |
| **トーン調整** | `0.10 ～ 10.00` | `1.00` | ※「トーン制御」が `なし` 以外のときに表示。選択したトーンカーブの効き具合（ロールオフ・露出係数）を調整します。 |
| **合成モード** | 選択 | `加算` | 元画像とグローの合成方法を選択します（詳細は下記参照）。 |

- **発光範囲の選択肢**
  - `全体`: 元画像の上および外側にグローを描画します。
  - `外側のみ`: 元画像の透明領域（外側）にのみグローを描画します。文字やキャラクターの輪郭から外へ漏れる光を作りたい場合に便利です。
  - `内側のみ`: 元画像の不透明領域（内側）にのみグローを描画します。領域拡張は行いません。
- **トーン制御の主な選択肢**
  - `なし`: トーン圧縮を行いません（`1.0` を超えた値はクリップされます）。**元の画像の色味を一切変えたくない場合**はこちらを選択してください。
  - `フィルムロールオフ` / `ACES Fitted` / `AgX` / `Uchimura` / `Uncharted 2` / `Lottes Filmic` など: 高輝度部分を自然に圧縮し、豊かな階調を残します。
  - `Khronos PBR Neutral`: 色相や彩度の変化を最小限に抑えつつハイライトを圧縮する方式です。
  - > **注意:** `なし` 以外を選択した場合、グローが乗っていない元画像部分も含め、オブジェクト全体にトーンカーブが適用されます。
- **合成モードの選択肢**
  - `加算`: リニア色空間で元画像にグローを加算します（$\text{orig} + \text{glow}$）。
  - `スクリーン`: 高輝度域での飽和を抑えたソフトな加算を行います（$\text{orig} + \frac{\text{glow}}{1 + \text{orig}}$）。
  - `グローのみ`: 元画像を出力せず、グロー成分のみを出力します。合成モードを別途変えたい場合やマスク用途に便利です。
  - `抽出プレビュー`: ぼかし処理を行わず、現在抽出されている領域のみを確認用に出力します。

## 使い方のヒント（Tips）

- **抽出範囲を素早く調整したい**
  `合成モード` を一時的に `抽出プレビュー` に切り替えると、どの部分がどれくらいの強さで抽出されているかをリアルタイムに確認しながら `抽出閾値` や `特定色のみ抽出` を調整できます。
- **元画像の色味をそのまま保ちたい**
  初期設定では `トーン制御` が `フィルムロールオフ` になっているため、オブジェクト全体のコントラストや色味がわずかに変化します。元絵の色を 100% 維持したい場合は、`トーン制御` を `なし` に変更してください。
- **プリズム・色収差風の滲みを作る**
  `波長拡散補正` で、たとえば `赤拡散補正` を `1.15`、`青拡散補正` を `0.85` のようにずらすと、光の輪郭に赤や青の色づきが生まれ、レンズの収差のようなリッチな表現になります。
- **アナモルフィックレンズ風の横長フレア**
  `縦横拡散比` を `0.70 ～ 0.95` 程度に設定すると、映画のレンズフレアのような横一文字のグローが作れます。`拡散の回転角度` で斜めに傾けることも可能です。

## 仕様上の補足

- **自動領域拡張について**
  通常オブジェクトへ適用した場合、`拡散半径` と `サンプリング幅`（および回転角度）に応じて自動で「領域拡張」が実行されます（`発光範囲` が `内側のみ` の場合、および `抽出プレビュー` 時を除く）。拡張後のサイズは AviUtl2 の最大画像サイズ（`image_max`）を超えない範囲に制限されます。
- **フィルタオブジェクト適用時の挙動**
  フィルタオブジェクトとして適用した場合は、AviUtl2 の仕様上「領域拡張」が行われないため、画面端の輝度が欠けて暗くなるのを防ぐ目的でサンプラーモードを自動的に `clamp` に切り替えて処理します。
